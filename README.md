# wg2sing

```bash
wg2sing <PATH_TO_WG_INI>
```

- `--system`: whether to use system networking (for example, create `wg0`)
- `--tag`: the created tag name
- `--wrap`: whether to create the wrapped config that can be parsed by sing-box directly

For more details, refer to upstream documentation: https://sing-box.sagernet.org/configuration/endpoint/wireguard/
